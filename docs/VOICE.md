# How Liam writes

Read from the current site. Use this for anything new, and only for new material.
His existing text is not to be edited.

## What it sounds like

- **Short, declarative, built from verbs.** "Evaluate it. Target it. Drill it. Understand it."
- **States what the firm does, then what it does not.** "We don't just write reports and
  hand over recommendations. We help run exploration programs."
- **Practical nouns in lists.** "Collar planning, RC and core logging support, sampling
  workflows, QA/QC, contractor coordination." No adjectives carrying the weight.
- **Field first.** The proof is experience on Nevada ground, not credentials or adjectives.
- **Names the client's decision.** The work serves "the client's next decision."

## Rules for new writing

- One idea per sentence. Cut the sentence before you add a clause.
- Say the thing plainly, then stop. No wind-up, no summary line at the end.
- Use the trade's real words (collar, intercept, cut-off) and define them once.
- Numbers get units and a source. If a number will go stale, say when it was checked.
- No hype words. No "world-class", "cutting-edge", "unlock", "leverage".
- No promises about results. Geology does not take instructions.

## The three depths

- **Float**: 3rd to 5th grade reading level. Everyday comparisons. No jargon without a picture.
- **Outcrop**: what an owner, investor or operator needs to make a decision.
- **Core**: methods, numbers, regulation cites, failure modes. Written for a peer.

Same facts at every depth. A deeper level adds detail. It never contradicts the one above.
